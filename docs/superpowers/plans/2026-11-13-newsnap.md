# NewSnapRecomp Implementation Plan

**Goal:** build the requested New Pokémon Snap port, beginning with a verified importer and binary-specific adaptation.
**Architecture:** pinned Astral Chain/TotK infrastructure, with isolated Snap tools and measured runtime changes.
**Tech Stack:** Python 3.12, ARM64-to-C lifter, clang 23, Windows x64, Vulkan.
**Spec:** docs/design.md

## Global Constraints

- Private inputs and all game-derived output stay outside Git.
- No Astral Chain offsets or timing patches may be applied to Snap.
- No performance improvement may be claimed without a comparable measurement.
- User requested direct implementation; execute inline without another approval round.

## Review Focus

- Wrong title/update and truncated input must fail before producing a usable extraction.
- Changed inputs must not reuse stale outputs.
- Failed or interrupted extraction must not appear complete.
- GPU preparation is separate from translating shader source.
- Public repository must contain no secrets or game content.
