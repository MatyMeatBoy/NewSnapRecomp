is used with a copy of the earlier tutorial save, a fresh profile and explicit

The interactive probe was stopped after the owner's Escape/close request. A
second background replay, physical input disabled, passed the camera-movement
instruction and reached Pikachu aiming. Its exploratory stick sequence overshot
the subject; a valid photograph is still **unverified**, not a confirmed renderer
or input defect. Preserve the screenshots and refine that route before changing
camera behavior. The two unprepared geometry programs were traced to one effect
library; their actual draw consumers remain unverified.

The fourth refined replay took the tutorial photograph and moved to subsequent
dialogue. At approximately native tick 20,160 it aborted during a later transition:
the SDK used `setjmp`/`longjmp` to return to an interior call continuation, which
the donor's ordinary native-function dispatch does not represent. The exact
private binary hash and trace are in that reproduction folder. The memory summary
after fatal is not evidence of an out-of-memory failure. A fix must handle the
nonlocal host stack transition, cached registers and context lifetime; adding an
interior start alone would not establish those contracts.

Capture the reached checkpoint from screenshots and save changes. An input log,
number of presents or exit code alone cannot establish accepted photography.
Retain the log, binary hash, effective settings and replay privately. Commit only
the nonproprietary route and findings after the checkpoint is verified.

feature complete merely to fit the v0.3 name. Report implementation, local
verification and hardware coverage separately; use the existing release-readiness
