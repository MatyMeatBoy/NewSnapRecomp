# Native/recomp AMD mechanisms: primary-source audit

Read-only research, 2026-11-14. Local baseline: Astral donor `248e0b29f308ca84a2d2092019cc60e7fc50ae85` plus the current NewSnap adapters. Public GitHub API commit/PR metadata, changed source and main-containment comparisons were inspected; the raw acquisition records remain private in `build/`. This is not an AMD hardware acceptance result and does not establish the cause of the owner's photos or device faults. No private game source, assets or logs were sent upstream.

## Repository and reversal checks

Verified current public repositories: captainj-sparrow/astral-chain-pc-recomp, Puddz/AstralChain-PC, valentderah/totk-pc-recomp, ly05010419/MacNativeGames and peiikai/LASRecomp. MacNativeGames targets Apple ARM64/Metal, so it is not direct AMD Vulkan evidence. These findings concern Switch 1 recompilation; they do not demonstrate Switch 2 compatibility.

Astral pinned-to-current comparison has eleven subsequent commits, mainly launcher support and game-specific graphic heap/AO/fog/LOD/draw-distance work. No justification to copy Astral game offsets into Snap.

A useful rejected lead: LASRecomp [62d0f6be2c5b1ac8a9acc6c226cfc47fa71e1057](https://github.com/peiikai/LASRecomp/commit/62d0f6be2c5b1ac8a9acc6c226cfc47fa71e1057) (2026-10-25 19:17) embeds vertex layouts in pipelines for AMD Windows, but [e45aa2e6f9ef90c2b747a629329ce349c9a71900](https://github.com/peiikai/LASRecomp/commit/e45aa2e6f9ef90c2b747a629329ce349c9a71900) reverts it at 22:35 that day. Both commits being ancestors of main does not mean the first behavior remains active. Historical PR-number API routes were unavailable; exact commit and reversal are the evidence. Do not port this as an accepted AMD fix.

## Bounded tests before any production proposal

Memory lifetime: use actual recording/submission/retirement functions with a fake timeline. Thread A records N and retains image/pool/Tex; thread B finalizes while only N-1 is submitted. Completing N-1 must release none of these, N must release each once. Cover recording splits, empty/cancelled records and shutdown without hanging waits. Claude owns this route; this report introduces no memory changes.

Translator: inspection of the actual twelve-patch prepared source reproduced the missing bounds. Subsequent implementation and actual-method tests are tracked separately in XLATE-SEMANTICS-07. No GPU was run during this audit. No FPS or AMD-photo-fix claim follows from source inspection.
