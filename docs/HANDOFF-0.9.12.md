## Findings to build on

**Scenery shadows (the owner's orange circles on the camp deck).** Experiments on the camp dialogue (static camera,
`tests/routes/intro.txt`, shot 3150), with `NEWSNAP_TEX_WHITE=<vk formats>` (white stand-ins by format, in
`snap_texpack.c`):

- BC6H (vk 143/144) light maps replaced by flat magenta tint the trees, house and deck: they are the scene's ambient /
  indirect light. ~40 % hold negative values (directional terms). The deck's dark shadows stay: **not from them.**
- BC4 (139) and BC5 (141, normals) white: shadows stay. BC3 UNORM (137) white: only the interface changes.
- sRGB colour textures white (138, 146, 134, 43): the deck and steps lose their hard dark shading; only soft lighting
  remains. **The pixelated shadows are painted into the colour textures** at low resolution.

So the HD shadows mode must enlarge the scenery's colour textures (the texture-pack pipeline,
`newsnap/texpack_gen.py`, Real-ESRGAN x4plus, BC1/BC3) to reach them. A camp test of that pipeline was running when
this was written (`runs/tps`, slow: seconds per texture). Next: compare shot 3150 with that pack against the original,
then make the mode save and enlarge colour textures as well (or merge it with the texture pack), keeping the game's
look (no recolouring; check UI textures are left out, e.g. by size or by the BC3 UNORM / interface formats).

**Pointer.** `main+0x643a70` (runs every frame, several threads) moves the pointer by speed × time / (1/60) and
hands the position to the interface through `[x21+0xc0]` vtable `+0xc0` with the clip name `cursor_mc`
(`main+0x643dd8`). If the owner still sees the pointer step at 144 fps after 0.9.11, check whether that position is
drawn every frame or only on interface steps (dense AC_SHOTS on the pause menu with a copy of a save that reaches
Florio); if only on steps, apply the position on the frames that only draw.

**Input.** The game reads the pad only through `main+0x43c160` (held) and `main+0x43c2d0` (pressed). Hardware data
breakpoints (`NEWSNAP_PAD_WATCH=1`, `NEWSNAP_PAD_WATCH_AT=<offset>`) plus `work-ss/updated/totk.map` name any reader.
