# Version 0.5 design and acceptance

The owner requested continuation after shipping 0.4, with VRR verification and
physical joystick testing on a second PC. The immutable 0.4 release is
`v0.4.0-alpha`, source `f4551afd0e9c8002fc3dca6502a1de1f9c2ddb7c`.

## Scope

The current release gate is [PENDIENTES.md](PENDIENTES.md). All owner-reported
fixes must be resolved and verified before publishing 0.5; review status is not
acceptance. Critical blockers include focus/HUD corruption, striped capture and
thumbnail images on RX 6900 XT in Original mode, tutorial photo acceptance through
the unchanged game logic, camera input drift, neutral transfer correctness,
frame pacing and the Home/update flow. Keep local NVIDIA evidence separate from
the owner's AMD results. Existing 0.4 owner data remains immutable during testing.

- Report actual display/presentation evidence separately from synchronization
  settings. Prefer optional Vulkan present-timing observations from the game's
  real swapchain. Missing extensions, unavailable results and monitor/swapchain
  changes produce an explicit unknown state. FIFO/mailbox/immediate alone must
  never be called VRR confirmation. Preserve native 30/60 FPS timing.
- Add a local controller test in the launcher: detected controller identity,
  mapping, live buttons/axes and capabilities. Keep game/profile and runtime
  replacement operations mutually exclusive while the test owns SDL. No input
  injection or vibration without a deliberate user action.
- Reuse verified private generated code during a local runtime rebuild when its
  original imports and generation recipe still match. Bound the cache, retain
  ownership metadata and reject corrupted/stale entries. Do not trust cached
  native executables or compiler objects without their own complete provenance.
- Extend course/photo acceptance on copies of saves, including the final neutral
  SDR policy and temporal presets. Preserve all 0.4 colors, Native AA/DLAA and
  update/controller features.

## Evidence contracts

Display support, driver enablement and observed presentation are distinct facts.
Each observation names its source, monitor/swapchain generation and timestamp.
The launcher should explain what was observed without inventing a green active
VRR indicator for unknown or conflicting results.

Controller reads must use the bundled SDL ABI and the same mapping rules as the
game. Absent, unrecognized, disconnected and multiple controllers remain
inspectable states. Closing the test releases its handles and lock, including
after initialization failure.

Private caches contain owner-derived code and remain local. Cache eviction may
only affect validated children of the dedicated cache root; saves/imports and
unrelated files are never cleanup targets.

Physical RX 6900 XT, monitor VRR and the owner's second-PC controller acceptance
depend on the actual hardware results. Automated/virtual evidence is reported
separately.
