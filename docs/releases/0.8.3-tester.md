# NewSnapRecomp 0.8.3-tester

**Tester build.** Replaces 0.8.2-tester.

- **Import NSP/XCI from the launcher (IMPORT-01).** Home → "Importar NSP/XCI…": choose the base
  game (NSP or XCI), the 2.0.1 update (NSP) and your `prod.keys`. The launcher runs the
  project's importer with the build kit's Python and a bundled hactool (SciresM/hactool at the
  donor's pinned commit with its patches, built from source with the SDK's clang; licence in
  `licenses/hactool-LICENSE.txt`), then selects the new GameData. Your files are only read.
  Extracted GameData folders still load as before.
- Photo research (SS-03) documented: the big photo on the selection screen is the game's
  360×240 BC1 thumbnail; the `AC_SS_PHOTO=1` experiment stays off.
