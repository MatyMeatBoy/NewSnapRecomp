# NewSnapRecomp 0.7.0-tester

**Tester build, not stable.** It exists to debug the RX 6900 XT's graphics failures with everything
integrated into `main` after 0.6. It does not fix those failures: it adds diagnostics and
elimination tests. The 0.6 and earlier artifacts do not change.

## Changes since 0.6.0-alpha

- **Photo diagnostics in the normal log** (PR #6): each photo-to-buffer copy writes `photo_log:` and
  `photo_trace:` with differing bytes, black rows and tiles. No PNG unless
  `NEWSNAP_PHOTO_TRACE_DIR`.
- **An `amd_diag:` line** at start-up with the effective test settings (PR #11).
- **A `pruebas-amd` folder** next to the launcher: six `.bat` files in elimination order that start
  the game with one setting each without touching `newsnap.ini` and save the log in
  `logs\pruebas`.
- **Shader translator** with defined semantics for bit fields and shifts (PR #9), with a verified
  binary pin.
- **Launcher:** starts after rebuilding and opens the game in interactive mode (PR #4, #5); video
  settings on a single page (PR #10); verification of runtime activation and cache cleanup
  (PR #7).
- AMD audit documentation (PR #8) and a handoff guide to debug on the RX 6900 XT
  (`docs/bugs/amd-debug-handoff.md`).

## Known state on AMD (unresolved)

On the RX 6900 XT with 0.6: a banded photo thumbnail inside the level, strips on the portrait,
plate and frame, squares on some models and closes with `device fault … write invalid` (all three
recorded, with FSR 4 on). Turning shadow on does not change it. Cause not established. It does not
happen on the RTX 4060.

## Checked

See the release body for the suite, the rebuild from the kit and the RTX test of this specific
producer. Nothing in this version was run on AMD before publishing it.

## Limits

- Labelled as a tester prerelease; it does not replace 0.6 as the reference.
- The `.bat` files were checked with a placeholder executable and their conservative combination
  passed the photo route on an RTX 4060 with the 0.6 runtime; not on AMD.
- More than 60 FPS, scales 125/150/200 % and complete routes are still unverified.
