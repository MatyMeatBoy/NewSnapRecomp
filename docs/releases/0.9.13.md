# NewSnapRecomp 0.9.13

- **Clearer picture options** in the launcher and the in-game menu: *Internal resolution*, then *Anti-aliasing*
  (Automatic, AMD FSR 4, FSR 3.1, NVIDIA DLSS or the game's SMAA), then *Performance scaling* (Off by default; Quality,
  Balanced or Performance only when you need more FPS). Anti-aliasing works at any internal resolution.
- **Cleaner edges above 100 %:** when the internal resolution is larger than the window (for example 150 % on a 1440p
  screen) the picture is reduced with an area average instead of a bilinear filter, so window frames and stair edges
  stay smooth.
- In-game menu: changing *Performance scaling* at an internal resolution above 100 % no longer switches the
  anti-aliasing to Original and locks the row; the row explains which value applies.
- In-game menu: pressing A on a value row no longer changes it (left / right change values; A only presses buttons).
