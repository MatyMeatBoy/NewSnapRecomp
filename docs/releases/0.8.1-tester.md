# NewSnapRecomp 0.8.1-tester

**Tester build, not stable.** New internal resolution, high FPS, higher-resolution shadows and
frame generation. The 0.8.0 and earlier artifacts do not change.

## What's new

- **Internal resolution above 100 % redone (SS-02, PR #21).**
  - Before, at 125–200 % the image covered a quarter of the window and photos came out cut. Now
    the game draws at its 1920×1080 and the runtime enlarges its 16:9 render targets on the host
    (scene, depth, HUD and half-resolution effects), like Witch Time and the emulators.
  - Scales 125, 133, 150, 175, 200, 250 and 300 %, and **«Según la pantalla»** (By display): the
    scale matching your monitor's or window's height (1440p → ×1.33, 4K → ×2).
  - The HUD, photos, thumbnails and evaluation work at any scale.
  - TV mode only and with temporal reconstruction off.
- **Shadow resolution** (1×, 2×, 4×) for the sun's shadow map, the vegetation's one. 1× by default
  (as the original).
- **High FPS: 90, 120 and 144** (FPS-01, PR #20, RTX tester), without touching game logic.
- **AMD FSR frame generation** (FG-01), **off by default**. It inserts a generated frame between
  every two real ones (60 → ~120 on screen). Needs FSR 3.1 or FSR 4 and a monitor of 120 Hz or
  more (or VRR). Uses AMD's official SDK 2.4 (`amd_fidelityfx_framegeneration_vk.dll`), without
  its swapchain, like the TotK recomp.
- `tools/pruebas-amd` cleaned up: normal, F12 dump, internal 150 % and 200 %.

## Checked on the RX 6900 XT (window, photo route)

| Test | Result |
|---|---|
| 200 % + 16:9 chain + 2× shadows, 60 fps, 540 s | exit 0, HUD/photos/evaluation correct, 1 % low 52–58 fps |
| 175 %, window maximised live | correct |
| «Según la pantalla» in 1440p fullscreen | 2560×1440 internal, correct |
| 120 FPS + 200 % + 2× shadows, `immediate`, 240 s | 120.0 fps average, 0 frames > 25 ms after start-up |
| FSR 4 Native AA + frame generation, `immediate`, 240 s | exit 0, real frames at exactly 16.667 ms (p95), correct image |

## Not checked / limitations

- RTX with this binary (FPS-01 was tested on an RTX 4060 separately).
- Frame generation: no «HUD-less» image (Snap's scene is linear before its tonemap), so moving HUD
  elements can leave trails. With `fifo` on a monitor below 120 Hz the game slows down. DLSS Frame
  Generation is not included.
- Higher-resolution photos: the big photo on the selection screen is the game's 360×240 thumbnail
  (the same as on Switch); pending as a mod.
- Ultrawide, active VRR and NSP/XCI import are still in the queue (`docs/PENDIENTES.md`).
