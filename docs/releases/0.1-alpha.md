# NewSnapRecomp 0.1 alpha

Primera alpha experimental de MatyMeatBoy para Windows x64 (CPU con AVX2 y
controlador Vulkan). No es un port completo ni una versión estable.

## Incluido

- Importación verificada de base y actualización 2.0.1 propias.
- Launcher en español: perfiles, preparación de shaders, controles y álbum.
- Vídeo básico y avanzado: ventana personalizada, pantalla completa, salida
  TV/portátil, escala interna nativa 50–100 %, FSR espacial/bilineal, nitidez,
  anisotropía, encaje, brillo, contraste, saturación y gamma.
- Límites de presentación 30/60 y modos FIFO, mailbox, inmediato y FIFO relajado
  con fallback. VRR depende del sistema; más de 60 FPS sigue en investigación.
- Nombre local sin diccionario de palabras de Nintendo, ajustes de hora del
  dispositivo, protección de cierre durante guardado y reinicio supervisado.
- Iconos originales de cámara y variantes favicon.

## Comprobado y pendiente

La compilación local, selftest de memoria/dispatch y prueba del loader pasan.
Pruebas aisladas alcanzan la escena 3D y el tutorial de cámara. La telemetría GPU
confirma cambios de tamaño de renderizado al 50/100 % sin errores registrados
en esos probes. Esto no acredita todas las rutas ni un rendimiento sostenido.

Quedan sin verificar un recorrido completo, evaluación/puntuación, persistencia
de fotos reales, sesiones largas y otras GPU. El lector del álbum tiene pruebas
con fotos sintéticas y cabeceras reales de bancos vacíos. Hay dos entradas de
geometry shader no admitidas. DLSS, XeSS, FSR temporal, HDR y efectos de sombras
específicos de la base no se anuncian como funciones adaptadas a Snap.

## Paquetes

El asset de GitHub contiene fuentes, herramientas y la base fijada; necesita
los archivos propios y una compilación local siguiendo README. Excluye datos,
claves y ejecutables derivados del juego.

El paquete privado solicitado para otro PC se entrega sólo como archivo local:
incluye el ejecutable de prueba, Python, dependencias, datos ya importados y una
copia del perfil local. Extrae todo y abre **Iniciar NewSnap.cmd**. Se reconstruye
la caché de shaders para la GPU de destino. La ejecución en ese segundo PC sigue
pendiente de prueba. Conserva el perfil original y usa la copia para probar.
