# NewSnapRecomp 0.5 alpha

[Release published on GitHub](https://github.com/MatyMeatBoy/NewSnapRecomp/releases/tag/v0.5.0-alpha).

A limited alpha for Windows x64. It stays a prerelease and is not marked Latest. The 0.4 release
and the private dev1 candidate keep their original artifacts; they are not overwritten.

## Changes

- SDR transfer by source and target format, without modifying the game's colour or adding the
  donor's saturation, contrast, gamma or HDR.
- Host import that requires visible/coherent memory and uses the managed path when those
  properties are not met. Draws with SSBO/image writes wait for their pipelines; async is not
  turned off for every draw.
- Relative mouse: invalidates the sample when capture or focus is lost/regained. Sensors: reset
  the fusion when the source/device changes, on disconnect, when motion is turned off or a read
  fails. Motion off does not enable sensors.
- Home with load/verify data, version, profile and launch independent of Updates. Repair of the
  same version and a local runtime rebuild when the recipe changes; the exact kit also for
  installed alphas.
- Automatic notices only for a newer stable. The manual catalogue allows published alpha/stable
  versions and repair; this alpha is chosen manually.
- ReKHCoM's original pixelated controller with Switch labels, a controller selector and SDL
  diagnostics. A native menu with Original, FSR 3.1, FSR 4 and DLSS, and native/Native AA,
  quality, balanced and performance presets according to real support.
- A private cache of generated code with verified provenance. An integer bridge for a resource
  worker with equivalence of results, state and registers.
- Claude's PR #1 integrated: a read-only audit of saved photos' banks/JPEGs, and its review fixes.

## Evidence and limits

The alpha was rebuilt from the final public build kit: fresh generation, 279 objects, memory/
dispatch self-tests and loader correct. 299 tests passed on Windows, CI and the independent
review of both packages.

On an RTX 4060, the exact alpha executable completed 540 s in Original 100 %, the tutorial
evaluation and the first expedition: two new photos (Pikachu and Vivillon), two clean thumbnails
and four identical GPU source/buffer transfers. Confirmed banks and transactions match; 75
protected profile/backup files stayed intact. Async stayed on. This control is not a performance
benchmark.

SHA256 of the locally rebuilt runtime:
`e0dcac87a708d1f5f7c5a0cf880525784a8ae077f06c1b37c67f4166045b8db4`. That derived executable is
not included on GitHub: it is generated from your own data.

The bridge's specific A/B, same executable and seed/cache per run, two reversed 40 s pairs,
lowered the local p99 from 42.970 to 25.469 ms. Median ≈16.67 ms; a maximum of 107.692 ms
remains with it on. Not a guaranteed improvement across the game or the removal of every hitch.

**Not physically verified:** the failures reported on the RX 6900 XT, the reticle across all AMD
motion/zoom, the colour of its display chain, the physical controller and FreeSync. FSR 4 depends
on the provider/GPU/driver; INT8 or FSR 4 support on the RX 6900 XT is not promised without
measuring it. No complete route was finished and not every scale or more than 60 FPS was
verified. Subject, scoring and tutorial logic stays intact. Pending states stay in
`docs/PENDIENTES.md`.

## Install and update

Download the **Windows** ZIP and extract it completely. Keep your own GameData folder and
profiles; GitHub does not distribute the game or the recompiled executable. The earlier 0.4
launcher only checks the latest stable: to move to this alpha, first download the Windows ZIP
from GitHub. The new launcher does offer the manual alpha catalogue; no automatic notification of
this delivery is expected. If you test it separately, copy GameData and check in Home that data
and profile point to that copy: old preferences may hold an absolute profile.

The launcher gets the build kit of this same version and revision if it needs to rebuild the
runtime. The kit contains a public recipe and portable tools; Python does not need installing.
Prepare graphics for the machine's GPU/driver. The same version can be repaired/reinstalled
without deleting owner data.

The only public assets are the Windows launcher, the build kit and their SHA256s. Never upload
GameData, imports, keys, saves, caches, photos or private runtimes.

### Saves from the previous version

This update does not regenerate photos that were already saved damaged. If the tutorial got
stuck on that profile, keep it and try an earlier complete backup in another copied profile (same
UID, without mixing banks or carrying later transactions). Subject evaluation is not skipped and
