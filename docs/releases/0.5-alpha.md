# NewSnapRecomp 0.5 alpha

[Release publicada en GitHub](https://github.com/MatyMeatBoy/NewSnapRecomp/releases/tag/v0.5.0-alpha).

Alpha limitada para Windows x64. Se mantiene como
prerelease y no se marca Latest. La release 0.4 y el candidato privado dev1
conservan sus artefactos originales; no se sobrescriben.

## Cambios

- Transferencia SDR según formato fuente y destino, sin modificar el color del
  juego ni añadir saturación, contraste, gamma o HDR del donor.
- Importación host que exige memoria visible/coherente y usa la ruta gestionada
  cuando no se cumplen esas propiedades. Draws con escrituras SSBO/imagen esperan
  sus pipelines; no se desactiva async para todos los dibujos.
- Ratón relativo: invalida la muestra al perder/recuperar captura o foco.
  Sensores: reinicia la fusión al cambiar fuente/dispositivo, desconectar,
  apagar movimiento o fallar una lectura. Movimiento apagado no habilita sensores.
- Home con cargar/verificar datos, versión, perfil y lanzamiento independiente
  de Actualizaciones. Reparación de la misma versión y reconstrucción local del
  runtime cuando cambia la receta; kit exacto también para alphas instaladas.
- Avisos automáticos solo de una estable más nueva. El catálogo manual permite
  versiones publicadas alpha/estables y reparación; esta alpha se elige manualmente.
- Mando pixelado original de ReKHCoM con etiquetas de Switch, selector de mandos
  y diagnóstico SDL. Menú nativo con Original, FSR 3.1, FSR 4 y DLSS, y presets
  nativo/Native AA, calidad, equilibrado y rendimiento según soporte real.
- Caché privada de código generado con procedencia verificada. Puente entero de
  un worker de recursos con equivalencia de resultados, estado y registros.
- PR #1 de Claude integrado: auditoría de bancos/JPEG de fotos guardadas, de solo
  lectura, y sus correcciones de revisión.

## Evidencia y límites

La alpha se reconstruyó desde el build kit público final: generación nueva,
279 objetos, autotests de memoria/dispatch y loader correctos. Pasaron 299 pruebas
en Windows, CI y la revisión independiente de ambos paquetes.

En RTX 4060, el ejecutable alpha exacto completó 540 s en Original 100 %, la
evaluación del tutorial y la primera expedición: dos fotos nuevas (Pikachu y
Vivillon), dos miniaturas limpias y cuatro transferencias GPU fuente/buffer
idénticas. Bancos confirmados y transacciones coinciden; 75 archivos protegidos
de perfil/respaldo permanecieron intactos. Async permaneció activado. Este control
no es un benchmark de rendimiento.

SHA256 del runtime reconstruido localmente:
`e0dcac87a708d1f5f7c5a0cf880525784a8ae077f06c1b37c67f4166045b8db4`.
Ese ejecutable derivado no se incluye en GitHub: se genera con los datos propios.

El A/B específico del puente, mismo ejecutable y semilla/caché por corrida, dos
pares de 40 s en orden inverso, redujo el p99 local de 42,970 a 25,469 ms. Mediana
≈16,67 ms; persiste un máximo activado de 107,692 ms. No equivale a una mejora
garantizada en todo el juego ni a la eliminación de todos los tirones.

**Sin verificar físicamente:** los fallos reportados en RX 6900 XT, retícula en
todo el movimiento/zoom AMD, color de su cadena de pantalla, mando físico y
FreeSync. FSR 4 depende del proveedor/GPU/driver; no se promete INT8 ni soporte
FSR 4 en RX 6900 XT sin medirlo. No se completó una ruta entera ni se verificaron
todas las escalas o más de 60 FPS. La lógica de sujetos, puntuación y tutorial
permanece intacta. Los estados pendientes siguen en `docs/PENDIENTES.md`.

## Instalación y actualización

Descargar el ZIP **Windows** y extraerlo completo. Conservar la carpeta GameData
propia y los perfiles; GitHub no distribuye el juego ni el ejecutable recompilado.
El launcher 0.4 anterior consulta solo la última estable: para pasar a esta alpha,
descargar primero el ZIP Windows desde GitHub. El nuevo launcher sí ofrece el
catálogo manual de alphas; no se espera una notificación automática de esta entrega.
Si se prueba aparte, copiar GameData y comprobar en Home que datos y perfil
apuntan a esa copia: preferencias antiguas pueden contener un perfil absoluto.

El launcher obtiene el build kit de esta misma versión y revisión si necesita
reconstruir el runtime. El kit contiene receta pública y herramientas portables;
no requiere instalar Python. Preparar gráficos para la GPU/driver del equipo.
Puede repararse/reinstalarse la misma versión sin borrar datos del propietario.

Los únicos assets públicos son launcher Windows, build kit y sus SHA256. Nunca
subir GameData, imports, claves, partidas, cachés, fotos o runtimes privados.
