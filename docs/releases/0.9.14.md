# NewSnapRecomp 0.9.14

- **SMAA anti-aliasing with levels:** Low, Medium, High (default) and Ultra, in the launcher and the in-game menu.
  It smooths jagged edges (window frames, stairs, cables) before the HUD is drawn, so text and menus stay sharp. It
  works at any internal resolution, and above 100 % the result is even cleaner.
- **FSR / DLSS are their own option again** ("Escalador"), off by default: use them for extra FPS or frame
  generation. While one runs, SMAA steps aside.
- **No console window** beside the game when it is opened from a shortcut, Steam or the folder.
- The game's light maps can now be read straight from your own game files (groundwork for building the HD shadows
  mode at install).
