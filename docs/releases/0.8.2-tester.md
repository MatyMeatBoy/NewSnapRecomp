# NewSnapRecomp 0.8.2-tester

**Tester build.** Polishes 0.8.1; artefacts of earlier versions are unchanged.

## Changes since 0.8.1-tester

- **Frame generation pauses itself when the monitor cannot show it (FG-02).** Generated
  frames are only made while the real frame rate is at most 0.55 of the monitor's refresh
  (60 fps needs about 110 Hz), the rule Weeping of the Empire (TotK recomp) uses. Below that
  only real frames are shown, so FIFO no longer slows the game on a 60/100 Hz monitor. A
  change needs 2 s of agreement.
- **CPU reads of enlarged textures are averaged (SS-03).** When the game reads an enlarged
  8-bit colour texture, each of its texels now averages the enlarged texels it covers instead
  of taking the nearest one. `AC_SS_PHOTO=1` (off) also enlarges the photo targets, as a first
  step toward higher-resolution photos.
- **English README with screenshots**, English `AGENTS.md` and work board.
