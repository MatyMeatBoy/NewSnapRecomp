# NewSnapRecomp 0.8.8-tester

**Tester build.** Replaces 0.8.7-tester.

- **Frame generation without HUD trails (FG-02).** FSR frame generation now gets a HUD-less image:
  Snap tonemaps the scene into a full-size RGBA8_SRGB image and then draws the interface into that
  same image through a UNORM view. When the interface pass begins, the image holds the scene
  without HUD; it is copied to a ring of three images keyed by the frame's prepare id and passed
  as `HUDLessColor`, so FFX keeps the interface out of the interpolation. No vendor branch. Menus
  have no tonemap pass and generate without it, as before.
- Archive board: 0.7.0-tester recorded as published (PR #14).

Tested on the RX 6900 XT, FSR 4 balanced + frame generation, `immediate`, photo route 240 s:
exit 0, 0 validation errors, HUD-less image active in gameplay, 60.0 fps real (1 % low 40–44).
Trails were not measured frame by frame; check moving HUD elements by eye. Not tested on RTX.
