# NewSnapRecomp 0.9.0-tester

**Tester build.** Replaces 0.8.9-tester. Launcher and in-game menu reorganised around NewSnap's own options.

## Launcher
- **Presets:** «Recomendado» (new default): internal resolution by display, AF 16×, shadows Auto, HD photo
  thumbnails, 60 FPS, automatic borderless window. Plus Original, Bajo, Medio, Alto and Ultra, now covering
  shadows and HD thumbnails. An existing `newsnap.ini` keeps its values: pick «Recomendado» to move to the new defaults.
- **«Mejoras» tab** (replaces «Mods»): HD photo thumbnails, shadow resolution, frame generation and the HD texture
  pack, each switchable. Gyro and mouse sensitivity moved to Controles.
- **Window size «auto»** (default): the desktop's size, borderless fullscreen.
- **Internal resolution «display»** (default): the 3D scene at the screen's height (1440p → 2560×1440). It adapts by
  itself: no supersampling while an upscaler runs or in handheld mode.
- The «Según la pantalla» frame-rate option was removed from the menus (with FreeSync it only lowered the frame rate);
  an old `fps = display` value keeps working.

## In-game menu (Minus + Plus)
- **Screen:** «Game internal resolution» replaces the donor's «Game resolution», which did nothing in Snap; «Aspect
  ratio» with ultrawide; «Automatic (desktop)» window size.
- **Enhancements** tab (replaces Mods): frame generation (greyed out without FSR 3.1/4), HD thumbnails, shadows with
  Auto, HD texture pack (greyed out without a pack).
- **Performance overlay:** «fps» shows `60 fps · FG +60 = 120` while frame generation runs; the full panel shows the
  real 3D size after the internal resolution.

## HD texture packs (TEXPACK-01, first part)
Dolphin-style packs by content hash: `NEWSNAP_TEX_DUMP=<folder>` dumps the colour textures the game loads; the
`texpack` folder next to `newsnap.exe` holds `<hash>.dds` files that replace them when sampled. `tools/texpack.py`
builds a pack from a dump with Real-ESRGAN. No pack is shipped (it is made from each player's own game); the
launcher button to build one is still to come.

Tested on the RX 6900 XT: photo route with the new menu rows (exit 0, 0 validation errors); texture dump (sRGB colour
textures only); menu screenshots. Tab switching and the texture pack in game were not exercised by the scripted tests.
