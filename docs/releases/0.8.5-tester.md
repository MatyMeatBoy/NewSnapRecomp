# NewSnapRecomp 0.8.5-tester

**Tester build.** Replaces 0.8.3-tester (there is no 0.8.4).

- **NSZ, XCZ and XCI import (IMPORT-02).** Home → "Importar NSP/XCI/NSZ…" now accepts the base
  game as NSP, NSZ, XCI or XCZ and the 2.0.1 update as NSP or NSZ. Compressed or cartridge dumps
  are first rebuilt as a temporary plain NSP next to the import (NCZ decoding follows
  nicoboss/nsz: zstd stream or NCZBLOCK blocks, AES-CTR re-encryption of each section) and every
  rebuilt NCA is checked against the SHA-256 in its file name, so a damaged dump stops with an
  error. The temporary NSP is deleted when the import ends.
- **XCI fix.** 0.8.3 offered XCI in the file picker, but the importer's NCA reader only parses
  NSP; XCI now goes through the same conversion (secure partition → NSP).

Tested: synthetic NSZ (stream and block), XCZ and damaged-NCZ cases (`tests/test_container.py`).
the dump in free space while converting.
