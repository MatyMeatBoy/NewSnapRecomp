# NewSnapRecomp 0.5.1 alpha

A fix of the 0.5 alpha, keeping the already published packages immutable.
[Published release](https://github.com/MatyMeatBoy/NewSnapRecomp/releases/tag/v0.5.1-alpha). It
does not vouch for a physical AMD fix.

## Scope

- The exact public kit included in Windows and pinned by hashes: a local rebuild without depending
  on GitHub access. A corrupt cache can be recovered from the verified bundle, keeping a
  quarantine and without touching imports/profiles.
- Bounded detection of portable GameData, the profile selector out of Home and helper consoles
  hidden without losing logs or the explicit CLI console.
- Original/Low/Medium/High/Ultra presets with explicit scale and AF, tooltips and technical names.
  Requested and effective presentation and the observed VRR state are independent; the game's
  colour is not changed.
- Visible NewSnap names and newsnap.log/newsnap.ini files. Compatible reading and the first save
  keep old files and preferences.
- Export diagnostics: a bounded local ZIP, redacted logs, the executable's real hash at start, the
  observed exit and a readable session analysis. It includes the reviewed CPU part of the maintainer's
  PR #2; its applet overlay is not integrated.
- Optional presentation trace from Options → Game, with separate acquire/fence/present/rebuild
  times and modes/images. It does not change queues, cap or VRR.
- Bounded logging of images' memory requirements. The AC_SNAP_POOL_BOUNDS=1 experiment stays off
  by default; it is not an AMD fix.

## Checked and pending

Suite before the identity change: 387 tests, one skipped for symlink permissions. Native adapter
tests and an independent review of recovery, logs/privacy and tooltips. The earlier fixes runtime,
producer 8ff756d, builds, passes selftest/loader and 20 Vulkan seconds on an RTX 4060 without a
close or modifying the legacy test INI. That does not validate this final package.

Final kit and launcher closed on e77393f4: 1,105 launcher files and 7,308 kit files verified
independently by hash/inventory. The Windows ZIP includes the kit and is about 286 MB. Install,
repair of the same version and extracting the kit without network pass; a real rebuild from its
portable Python and activation verified. The frozen launcher passes its self-test with a clean
PATH and a real GUI export with the analysis of a synthetic session.

The rebuilt binary passes two short RTX sessions, FIFO and Mailbox, with the four trace categories
and the effective mode checked. They are not an A/B benchmark or a complete photo acceptance.
Still pending: RX 6900 XT/FreeSync/controller acceptance, the reported photos/thumbnails and
colour, the intro head and PR #2's applet answers. Do not declare the alpha stable or blame every
spike on shaders: the cold test identifies some compilation cases, while the earlier 107 ms spike
still has no single cause.

Publication verified: tag e77393f4, four assets with the same hashes/sizes, prerelease without
Latest, real Windows download/stage and the automatic stable filter correct. The alpha appears in
the manual catalogue and generates no stable notice. It contains no game, saves, photos or keys;
the rebuild uses your own verified data. Do not overwrite the 0.4 or 0.5.0-alpha assets.
