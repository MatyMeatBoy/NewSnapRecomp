# NewSnapRecomp 0.9.24

- RecompLauncher integration: Easy Setup with your imported game folder or supported containers, headless play, session settings and Big Picture/controller hints. The complete Windows package includes its matching offline build kit and manifest.
- Move regenerable shader metadata writes from the render path to the existing cache autosave worker, with bounded memory, ordered synchronous fallback and explicit preparation/exit drains. Existing shader caches are retained.
- Avoid redundant internal-resolution/upscaler configuration queries on every draw when HD photo thumbnails already require scaled-image handling. Live settings remain immediate.
- One **HD shadows** option controls enhanced scenery shadow maps and 4x real-time shadows. Missing maps prompt once before local generation, showing **up to 6 GB / about 35 minutes**. Declining remembers original shadows; enabling later can resume. Startup preparation supports cancellation and preserves completed maps. Existing explicit Off settings remain Off.
- On supported Windows filesystems, new generated shadow files inherit lossless NTFS compression. Existing packs are untouched; unsupported filesystems use normal storage. DDS bytes, lighting and colour remain unchanged.

## Checked

661 regression tests passed (15 environment-dependent skips), independent code and worker review, JSON schema and packaging checks, frozen launcher selftest and real inherited stdout/stderr. The clean native 0.9.24 runtime builds with the pinned toolchain; selftest/module-loader and copied-profile gameplay are checked separately from the public launcher. No game-derived executable or data is published.

Matched warm-camera repeat on an RTX 4060 Laptop (144 FPS cap, 1280x720 window, 1920x1080 internal, upscaling/FG/HD shadows off): median frame interval **7.66 → 7.04 ms**, p95 **12.82 → 9.37 ms**, p99 **16.52 → 11.96 ms**. Frames above 16.67 ms: 22/2393 → 4/2653. Two candidate outliers still exceeded 25 ms (maximum 27.16 ms). These are local route results, not a universal FPS guarantee or an HD-on benchmark.

Cold-cache metadata caller median **17.785 → 5.481 ms** across 239 translations per run; SPIR-V flushing remains synchronous and its cost increased in that pair. Standalone preparation rebuilt 245 recorded variants with zero translation/driver failures.

Six real generated shadow DDS copies retained identical bytes/hashes while using **1,966,936 → 363,464 storage bytes** with NTFS compression. This small sample does not establish the whole mod’s size or savings; transparent decompression costs CPU work.
