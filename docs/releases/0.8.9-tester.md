# NewSnapRecomp 0.8.9-tester

**Tester build.** Replaces 0.8.8-tester.

- **Ultrawide (experimental, ULTRAWIDE-01).** Vídeo → Relación de aspecto → «Ultrawide · vista más
  ancha (experimental)». On a screen or window wider than 16:9 the 3D view is widened at the sides
  with the game's proportions; the HUD stays proportional in the middle; photos are taken from the
  usual 16:9 view; menus are shown 16:9 with bars. Details and limits: `docs/ULTRAWIDE.md`.

Tested on the RX 6900 XT in a 2520×1080 window, photo route 450 s: exit 0, 0 validation errors.
