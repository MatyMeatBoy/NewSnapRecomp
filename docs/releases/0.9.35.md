# NewSnapRecomp 0.9.35

- **Play prepares graphics automatically.** The launcher prepares the available
  shaders and recorded Vulkan pipelines before gameplay. After a runtime
  update, choose **Build and play** to rebuild locally and continue in the same
  flow. Compatible cache files and completed HD maps are reused. If shader
  preparation fails, the game can compile the remaining variants during play.
- **Installed HD textures and shadows get a head start.** Startup reads up to
  128 MiB of DDS data per enabled pack into the system's file cache. The
  runtime uploads textures for each scene as it needs them.
- **HD shadows are the first-time choice.** The launcher asks before generating
  missing HD shadow maps, which can take about 35 minutes and up to 6 GB.
  Choosing No uses original shadows and remembers the setting. Interrupted
  generation resumes from completed maps.
- RecompLauncher play automatically prepares available shaders and installed
  HD resources. Headless generation of missing HD shadows requires an explicit
  enabled setting or prior consent.

Natively tested camera-pacing results and the open RX 6900 XT / FreeSync
acceptance are documented in the [0.9.30 notes](0.9.30.md). Unseen shader
variants and textures still load on first use when needed.
