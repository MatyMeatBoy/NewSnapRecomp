# NewSnapRecomp 0.2 alpha

MatyMeatBoy's Windows `.exe` launcher with its own icon, application metadata and bundled
dependencies. The owner's data stays separate.

Requires Windows x64, an x86-64-v3 CPU (AVX2/FMA/BMI, among other capabilities) and a Vulkan 1.3
GPU/driver with the features the backend requires. SSE4.2 or any card that advertises Vulkan is
not enough. The runtime checks for missing features. Current physical tests are on an NVIDIA RTX
4060; AMD remains unverified on real hardware.

## Usage

1. Extract the **whole** `windows` asset of this release.
2. Copy your `GameData` or `newsnapGameData` folder next to `NewSnapLauncher.exe`.
3. Open `NewSnapLauncher.exe`. Keep `_internal` and the ZIP's other folders.

Python does not need installing. The public executable does not contain the game. Your own folder
includes the imported data, its generated native executable, shader entries and profile. It must
match this runtime version; to play it needs neither keys nor the original NSPs.

## Changes

- Basic/advanced Video, Audio, Game and Controls with help and scrolling.
- TV/docked by default and a handheld option. The choice is kept.
- Native scales 50–100 % and **experimental, TV-only** supersampling of 125 %, 150 % and 200 %.
  2× means double on each axis.
- Custom window, FIFO/mailbox/immediate/relaxed FIFO, spatial or bilinear FSR, sharpness,
  anisotropy, fit and colour settings.
- Volume and mixer prefill; language requested from the game.
- Remapping of 24 actions, controller layouts, independent dead zones, rumble, motion and mouse
  sensitivity; restore controls.
- A read-and-export album; relative profiles that follow the folder.
- The `.exe` preparation process with correct restoration of its records.

Scales above 100 % use Snap's engine resize. A handheld test found misaligned geometry and black
borders without API errors: that combination is blocked in the launcher and does not change the
handheld resize in the runtime. Handheld mode stays available at 50–100 %.

If the enlarged image cannot be allocated, the runtime ends with a message to lower the scale to
100 % and restart; it offers no automatic supersampling recovery. The default setting keeps the
game's native resolution.

## Alpha limits

The probes cover start-up, the first scenes and the tutorial; they do not vouch for a complete
route, evaluation/scoring, persistence of real photos or long sessions. The visual comparison is
limited to the reviewed screenshots. Two geometry shader entries are not supported. Other GPUs and
the second physical PC are still to be tested.

DLSS, XeSS, temporal FSR, HDR, the donor's specific shadow effects and more than 60 FPS have no
verified adaptation for Snap yet. VRR depends on the system. The current mixer only has a master
volume.
