# NewSnapRecomp 0.9.20

- **NVIDIA DLSS frame generation** (RTX 40 and 50 series, experimental): «Generación de fotogramas → NVIDIA DLSS» in
  the launcher and the in-game menu. One generated frame between two real ones, with DLSS as the upscaler (any mode,
  full resolution included). It pauses by itself when the monitor cannot show the extra frames and keeps the HUD out
  of the interpolation, like the FSR one. Fast limb movement can show the usual frame-generation blur.
- **New launcher look:** its own title bar (minimise, maximise, close, drag, double click), a navigation button with
  an icon for each section, textured background and soft shadows drawn by the launcher itself, and the Nunito font
  (open licence).
- **The launcher gets out of the way when the game starts**, and closes when the game ends. A fault kept the window
  open before.
- **«Verificar» / «Jugar»:** after an update, or whenever the game data must be checked again, the main button says
  «Verificar»; when the check is done it changes to «Jugar» by itself.
- **«Generar sombras HD» has its own progress bar**, and every progress bar fills from left to right with the real
  amount, or moves steadily when the amount is not known.
- **Faster starts with unchanged files:** the launcher remembers the files it already verified (your game data, the
  game runtime, the rebuild tools, the HD shadows and the prepared shaders) and does not read them again unless they
  changed. Shader preparation no longer runs before every start when nothing is new. «Verificar datos» and
  «Verificar / reconstruir juego» still read everything.
- **HD texture packs are hidden** in the launcher and the in-game menu: only shadows are enlarged.
- Fixed: a synchronisation fault in the HUD-less picture of FSR frame generation that could show up as a rare
  graphics error.

Not checked in this version: DLSS frame generation on RTX 50 (one generated frame is used) and on any card other
than an RTX 4060; the launcher's window on Windows 10, with display scaling above 100 % or on a second monitor; the
faster shader check on a GPU run after a driver update.
