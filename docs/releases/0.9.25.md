# NewSnapRecomp 0.9.25

- Added verified NUP v1 import alongside the existing containers and imported
  GameData. Complete supported decrypted content needs no keys. Import checks
  supported NSO identity, all modules and every RomFS file before publishing a
  deterministic runtime image.
- Added verified per-user installation fallback for protected folders and a
  separate migration of read-only game data into a new writable location.
  Original inputs and profiles are preserved.
- Added controller navigation and modal file/folder/confirmation dialogs to the
  local launcher, including setup before GameData exists. The pinned SDL runtime
  ships in the public package; input hands off before launching the game.
- Added optional complete profile backups to a user-selected sync folder, with
  streaming ZIP64 archives, integrity checks, three-copy retention and restore
  into a new profile. Files above 64 MB are covered by this independent option.
  A save pending recovery causes an explicit warning rather than a stale backup.
- Added **Original appearance** as an optional preset. Existing defaults and
  saved settings do not change. Selecting it explicitly applies native scale
  and filtering, 30 FPS, neutral colour, original shadows/photos and no frame
  generation or menu interpolation.
- Integrated the pinned official game-side Recomp Achievements SDK with a bounded
  worker and a verified changed-save commit event. Without a launcher session it
  is inert. The hosted achievement list remains inactive; see the limits below.

## Checks and limits

The regression suite passes 800 tests (17 environment-dependent skips); an
additional real SDL virtual-controller test checks mapped navigation and hotplug.
The native candidate builds with the pinned Windows toolchain and passes host
selftest and owner-module loader checks. A private real 2.0.1 NUP roundtrip
validated all 3,310 RomFS files and four ExeFS modules, then completed a scripted
course/camera route with a copied profile using the normalized image. No game
data, keys, owner saves or game-derived executable are distributed.

RecompLauncher's external cloud feature still excludes files above 64 MB. The
new full backup uses a separately chosen folder and its sync provider; it does
not change that service's limit. No authoritative whole-container CRC/size has
been invented for verified-dump badges.

The owner achievement hub rejects Switch metadata and requires a genuine
game-completion achievement. No list was stored or enabled. Saving is not game
completion, and no leaderboard or unverified progression hook is claimed. See
[achievement status](../ACHIEVEMENTS.md) and the [SDK report](../RECOMPLAUNCHER.md).

Physical-controller acceptance and RX 6900 XT/144 Hz acceptance remain pending.
The prior isolated camera spikes and reported course-entry image remain open;
this release does not claim universal stutter elimination or a speculative
transition fix. It retains the verified 0.9.24 runtime performance changes.
