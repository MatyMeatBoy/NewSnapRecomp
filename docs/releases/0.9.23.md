# NewSnapRecomp 0.9.23

- The launcher starts in English on English Windows, Spanish on Spanish Windows, and English for other unsupported system languages. It uses the Windows display language, separately from regional formats and the game's language.
- A visible English/Español selector remembers your choice. Changing language reopens the launcher in the same process and preserves pending settings.
- One persistent main button: Load game → Verify → Checking game → Build game when required → Play. Checks and builds run in the background; no second Play button appears on Home.
- Original promotional pictures and logo remain included. Remove the decorative Lental/field-journal captions beneath them.
- Explain where imported data will be saved, and that existing GameData folders are used in their current location.

This release changes the launcher. It does not claim a fix for the reported transient Pokémon image during course transitions or change in-game timing, scoring or progression. Smooth-menu interpolation remains experimental.

Validation: launcher/settings/update/packaging regressions, English/Spanish page construction, language-restart settings retention, native-button state tests, asynchronous integrity assessment and stale-result handling. Independent review found one runtime-label issue; corrected before release. Frozen executable and public archive validation are recorded in the release handoff.

Source validation: 626 tests, 69 environment-dependent skips, no failures. Frozen launcher selftest passes; all three original promotional images match their source bytes. Language switching and pending-settings retention tested in live Tk windows.
